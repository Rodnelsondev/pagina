# Projeto de estudo: login com efeito glass

Este projeto foi criado como parte do meu aprendizado em programação web, com ajuda da inteligência artificial para entender melhor a estrutura HTML, CSS e a lógica de interface.

## Objetivo

Praticar e melhorar o uso de:
- HTML
- CSS
- organização de elementos na página
- estilos visuais modernos
- criação de formulários de login e cadastro
- efeito glassmorphism
- animação de fundo

## Tecnologias usadas

- HTML5
- CSS3

## Estrutura do projeto

- `index.html` — estrutura da página de login
- `style.css` — estilos visuais e animações do fundo

## Observação

Este projeto é uma base simples de estudo, criada para praticar a construção de interfaces e entender melhor como os elementos visuais funcionam em conjunto.

## Sobre o aprendizado

Estou estudando programação com ajuda da IA, usando a ferramenta como suporte para tirar dúvidas, entender conceitos, revisar arquivos e melhorar a lógica dos códigos.

## Como abrir o projeto

1. Abra o arquivo `index.html` em um navegador.
2. Ou use um servidor local simples para visualizar melhor.

Exemplo:

```bash
python -m http.server 8000
```

Depois abra no navegador em:

```txt
http://localhost:8000
```

## Observações finais

Este é um projeto inicial de estudo, então ainda pode ser melhorado com:
- JavaScript para alternar entre login e cadastro
- validação de formulário
- autenticação real
- integração com backend
